# 7. Related Work

**State outside the prompt.** Code as an agent's action space [@wang2024codeact] and code execution in which intermediate tool results stay in the execution environment [@jones2025codemcp] are established practice; filtering web results with code before they reach the context raised Claude Opus 4.6 on BrowseComp from 45.3 to 61.6% [@anthropic2026dynamicfiltering]. RLMs place the material a model works on in a REPL; on a 1,000-document variant of BrowseComp-Plus given as input, an RLM with GPT-5 scored 88.0% without sub-calls against 70.5% for a compaction agent [@zhang2025rlm]. Closest to us are agents that keep documents as files and read them with shell tools: Codex with GPT-5 answers 88.5% of 200 BrowseComp-Plus questions over the corpus as files [@cao2026codingagents]; direct corpus interaction (DCI) and Dr-DCI search the corpus or a per-question workspace with shell tools [@li2026dci; @lu2026drdci]. OpenSaC and Scroll let agents keep search results or tool outputs in program state and print only selected parts [@liu2026opensac; @lin2026scroll]. Fetch-then-Explore writes fetched pages to a per-question workspace and reads them with grep and read tools, while search results still enter the prompt [@liu2026fte]; we compare with it directly (Section V-A). Agentica's GPT-5 REPL agent searches 200 results at a time (78.4% on the leaderboard) [@bcpleaderboard]. RISE varies width only inside large workspaces [@zhuang2026rise]. Holding results outside the prompt can also hurt: Sen et al. [@sen2026grep] found that delivering grep results as files rather than inline lowered accuracy in nine of ten model–harness pairs on chat histories (in the worst case from 93.1 to 55.2%). State outside the prompt pays only if the model reads it back. Programmatic search agents (PSA) compare a query-only agent with tool and code agents sharing a candidate workspace on BrowseComp-Plus, varying interface, not width [@qian2026psa]. Pi-Serini caches rankings of up to 1,000 BM25 hits outside the context and pages through them (83.1% with GPT-5.5) [@hsu2026piserini]. We propose the architecture for deep search and isolate, under equal caps and with gold labels, which of its components carries the gain.

**Long prompts and context management.** Models degrade as prompts grow even with perfect retrieval [@hong2025contextrot; @liu2024lostmiddle; @du2025contextlength]. Remedies summarise the history [@wu2025resum] or mask stale tool results; masking helped most models on BrowseComp-Plus, with fetched pages kept reachable in a pool [@zhang2026masking].
